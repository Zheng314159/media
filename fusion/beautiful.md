# 基础磨皮美颜，可以这样排：
[原始视频] → [节点1：基础调色] → [节点2：肤色选择+磨皮] → [节点3：人脸提亮] → [输出]
节点 01：保持默认，用来做基础调色（曝光、对比度、白平衡）。
节点 02 (Shift+S)：加一个新串行节点，专门做皮肤磨皮。
节点 03：再加一个节点，提升肤色亮度或加锐化。
# 保持对比度和锐度不受影响，可以用并行节点：
         ┌─ [节点2：肤色磨皮]
[原始] ──┤
         └─ [节点3：整体调色] → [合成输出]

| 节点编号       | 功能       | 说明                 | 建议操作                                                       |
| ---------- | -------- | ------------------ | ---------------------------------------------------------- |
| **01（默认）** | 基础调色     | 打开 Color 页就自带，不用添加 | 调整曝光、对比度、白平衡，让画面正常                                         |
| **02**     | 肤色磨皮     | 新建串行节点（`Alt + S`）  | 用 **Qualifier（取色器）** 选中皮肤 → 加 Blur/Sharpen 模糊，轻微磨皮（10–20%） |
| **03**     | 人脸提亮     | 新建串行节点             | 用 **Power Window（遮罩）** 框住脸部 → 提亮 Gamma / Gain，让肤色更透亮       |
| **04**     | 五官增强（可选） | 新建串行节点             | 加 **锐化（Sharpen）**，轻微增强眼睛/嘴巴细节，避免假面感                        |
| **05**     | 整体校色     | 新建串行节点             | 全局微调对比度、饱和度，保证画面统一                                         |

[01 基础调色] → [02 磨皮] → [03 提亮脸部] → [04 五官增强] → [05 整体校色] → 输出

| 数值范围           | 效果               | 适合场景                     |
| -------------- | ---------------- | ------------------------ |
| **-20 \~ -10** | 明显柔化，皮肤平滑，毛孔细节减少 | 强化磨皮效果，用于近景人像或需要美颜的短视频   |
| **-10 \~ -5**  | 轻微柔化，自然磨皮        | 常规人像视频，既保留质感又能优化皮肤       |
| **-5 \~ 0**    | 几乎无影响，微弱柔化       | 轻微修饰，适合想保持自然感的 vlog      |
| **0 \~ +5**    | 略微增强细节           | 让画面更清晰，但对皮肤影响不大          |
| **+5 \~ +15**  | 明显锐化，五官更立体，细节更突出 | 适合强调眼睛/嘴巴/发丝等细节，但皮肤可能显粗糙 |
| **+15 以上**     | 过度锐化，容易出现噪点和“假边” | 不推荐人像使用，适合工业、建筑、风景画面     |
